Đưa nhân vật vào Unreal

Dùng Unreal Engine 5 trên cùng máy. Chạy ở Editor, không bấm Play.

  1. Mở project và level môi trường bạn muốn dùng.
  2. Trong Edit → Plugins, bật Python Editor Script Plugin và Editor Scripting Utilities. Khởi động lại nếu được yêu cầu.
  3. Mở Output Log, đổi chế độ ô lệnh sang Python. Dán lệnh dưới đây và Enter.
  1. Quay lại trang này, bấm Link Unreal. Khi nhận được frame, trạng thái sẽ chuyển xanh.
  2. Trong Outliner tìm BL_Anchor_MOVE_ME, chọn và nhấn F. Di chuyển hoặc xoay anchor để đặt nhân vật vào cảnh.
Bật Realtime cho viewport (Ctrl+R). Nếu chuyển sang cửa sổ web làm Unreal chậm, tắt “Use Less CPU when in Background” trong Editor Preferences. Giữ tab web hiển thị, có thể đặt hai cửa sổ cạnh nhau.

Nếu đổi level, chạy lại lệnh. Nút ngắt link giữ nguyên tư thế cuối. Xem README để dọn nhân vật hoặc xử lý lỗi.
